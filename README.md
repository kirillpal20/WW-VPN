# VPN Subscription Bot

Telegram-бот, который раз в час проверяет VLESS-сервера из твоего форка
(`kirillpal20/vpn-vless-configs-russia`, файл `output/vless.txt`), отбирает
топ-10 самых быстрых рабочих и выдаёт каждому пользователю персональную
ссылку-подписку.

Работает целиком на бесплатном тарифе Render: сам бот + выдача подписки —
это один веб-сервис, а "раз в час" реализовано через внешний бесплатный
будильник (cron-job.org), потому что у Render Cron Job — платная фича.

## Из чего состоит

| Файл | Что делает |
|---|---|
| `parser.py` | Разбирает `vless://...` ссылку на части |
| `xray_test.py` | Реально проверяет сервер через локальный xray-процесс |
| `checker.py` | Скачивает список серверов, проверяет всё, сохраняет топ-10 |
| `storage.py` | Хранилище (Redis) — общая "база" между ботом и чекером |
| `bot_server.py` | Telegram-бот (вебхук) + выдача подписки + запуск проверки по секретной ссылке |
| `build.sh` | Устанавливает зависимости и скачивает xray-core при деплое |
| `render.yaml` | Описание для Render — разворачивает бота и базу одной кнопкой |

## Деплой на Render — пошагово

### 1. Создай бота в Telegram
Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → следуй инструкциям →
получишь **токен бота** (строка вида `123456:ABC-DEF...`). Сохрани его.

### 2. Залей этот код к себе на GitHub
Создай новый (свой собственный, не форк) репозиторий, например `vpn-sub-bot`,
и загрузи туда все файлы из этой папки.

### 3. Зарегистрируйся на [render.com](https://render.com)
Через GitHub-аккаунт — так удобнее всего, карта не нужна.

### 4. Разверни через Blueprint
- В панели Render: **New** → **Blueprint**
- Выбери свой репозиторий `vpn-sub-bot`
- Render сам прочитает `render.yaml` и предложит создать 2 сервиса:
  `vpn-sub-bot` (веб) и `vpn-sub-redis` (база)
- Нажми **Apply**

### 5. Впиши секреты
После создания сервисов зайди в `vpn-sub-bot` → **Environment**:
- `BOT_TOKEN` → вставь токен от BotFather
- `BASE_URL` → адрес твоего сервиса, Render покажет его в виде
  `https://vpn-sub-bot-XXXX.onrender.com` — скопируй и вставь именно его

`WEBHOOK_SECRET` и `CHECKER_SECRET` Render сгенерирует сам — трогать не надо.

Сохрани — сервис сам передеплоится с новыми переменными.

### 6. Настрой бесплатный "будильник" для проверки серверов

⚠️ **Важно:** у Render на бесплатном тарифе нет полноценных Cron Job (это
платная функция), поэтому проверку серверов раз в час запускает **внешний**
бесплатный сервис-будильник.

1. Зайди в панели Render → `vpn-sub-bot` → **Environment**, найди значение
   `CHECKER_SECRET` (Render сгенерировал случайную строку) — скопируй его.
2. Зарегистрируйся на [cron-job.org](https://cron-job.org) (бесплатно, без карты).
3. Создай новую задачу (**Create cronjob**):
   - **URL**: `https://<твой-адрес>.onrender.com/internal/check/<CHECKER_SECRET>`
     (подставь свой домен и скопированный секрет)
   - **Schedule**: каждый час (`Every hour`)
4. Сохрани. Теперь раз в час этот внешний сервис будет стучаться к твоему
   боту и запускать проверку — заодно и "будить" сервис, если он заснул.

### 7. Проверь
Напиши своему боту `/start` в Telegram. Если сервис "спал" — первый ответ
придёт с задержкой 30-60 секунд, это нормально. Дальше бот должен сразу
прислать тебе ссылку на подписку.

Если список серверов пока пустой (чекер ещё не отработал ни разу) — напиши
`/update`, чтобы запустить проверку вручную и не ждать первого часа.

## Важный момент, который нужно будет проверить самому

В `build.sh` зафиксирована конкретная версия `xray-core` (`v25.1.30`).
Я не могу проверить из песочницы, актуальна ли она прямо сейчас — у меня
нет доступа в интернет при написании кода. **Перед первым деплоем зайди на
https://github.com/XTLS/Xray-core/releases и сверь номер последнего релиза**,
если он другой — поправь строку `XRAY_VERSION` в `build.sh`.

## Ограничения бесплатного тарифа Render, о которых стоит помнить

- Веб-сервис "засыпает" после 15 минут без запросов, первый ответ после сна
  идёт с задержкой ~30-60 сек — это нормально для личного проекта, не баг.
- 750 бесплатных часов работы сервиса в месяц на весь workspace — с одним
  ботом и одним кроном тебе за глаза хватит.
- Free Redis (Key Value) на Render имеет ограничение по памяти — для десятка
  ссылок и списка токенов пользователей это несущественно.
